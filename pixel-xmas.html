Pixel Xmas

About the Project

In this project we aim to explore the greatest gift that comes with Christmas: Peace and comfort.

To represent this, we propose the creation of a loop, which consists of a gift which when ‘unwrapped’ reveals an abstract object inside that changes according to the audio being played.

An artistic perspective on feelings that are well established during the Christmas season.
